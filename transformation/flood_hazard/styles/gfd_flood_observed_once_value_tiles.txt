Value tile encoding:
encoded = R + 256 * G + 65536 * B

Decode:
if encoded == 0, value is nodata
otherwise observed_once = encoded - 1

Observed-once values are binary:
0 = never observed flooded
1 = observed flooded at least once in the GFD 2000-2018 catalog, excluding permanent water.
